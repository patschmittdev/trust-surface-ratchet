# Code of Conduct

Treat contributors and users with respect. Discuss ideas and changes with
specific evidence, acknowledge uncertainty, and accept constructive feedback.
Make room for people with different backgrounds and levels of experience.

Harassment, discrimination, threats, personal attacks, sexual attention,
deliberate disruption, and sharing another person's private information without
consent are unacceptable. These expectations apply in repository discussions
and other project spaces.

Report concerns through GitHub to the maintainer, or ask the maintainer for a
private channel before sharing sensitive details. Do not post private
information in an issue or discussion.

The maintainer may remove inappropriate content or restrict participation in
response to conduct that violates these expectations. Apply these rules fairly
and consider the context and impact of the behavior.
